## 🚀 Selected Projects

### [CollegeConnect](https://github.com/peanut-man/CollegeConnect)
An AI-powered campus event platform built with React, Node.js, Express, MongoDB, Redis, and BullMQ.
- Developed REST APIs, authentication, and role-based access workflows.
- Integrated an LLM-powered event assistant for natural-language event discovery.
- Used Redis-backed workflows and background jobs for supporting platform features.

### [Hybrid Text-to-SQL Table Retrieval](https://github.com/peanut-man/text2sql_retrieval)
A table retrieval system that helps identify relevant database tables for natural-language questions.
- Combines dense semantic retrieval, BM25 lexical search, and schema-graph expansion.
- Includes an offline metadata-enrichment pipeline and a retrieval evaluation workflow.
- Achieved **0.848 Recall@5** and **0.639 F1@5** in the project evaluation.
